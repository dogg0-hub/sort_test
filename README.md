# 概要
バブルソートと選択ソートをNext.jsにて実装したものです。

## 想定するテストケース
###  バブルソート
重複を含む数値型の配列(分数を含まない)
###  選択ソート
重複のない数値型の配列(分数を含まない)

## Getting Started
### Step1
```bash
npm install
```
### Step2
```bash
npm run dev
# or
yarn dev
# or
pnpm dev
# or
bun dev
```
### Step3
Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

## ディレクトリ構造
### バブルソートの実装
`http://localhost:3000/bubble`<br>
ファイルパス：app\page.tsx

### 選択ソートの実装
`http://localhost:3000/sentaku`<br>
ファイルパス：app\sentaku\page.tsx
